# mongolia rodent sdm

## Project overview

This repository contains an R-based workflow for modeling the environmental suitability of rodent species in Mongolia using boosted regression trees (BRTs). The workflow integrates georeferenced occurrence records with environmental predictors to examine species–environment relationships and generate spatial predictions of habitat suitability.

Understanding the environmental factors associated with rodent distributions can help identify areas of potential ecological and public health importance and inform future surveillance of rodent-associated pathogens.

## Objectives

- Prepare and spatially process rodent occurrence records.
- Integrate occurrence data with environmental predictor layers.
- Generate pseudoabsence records for presence–absence modeling.
- Fit species-specific boosted regression tree models.
- Evaluate predictive performance across repeated training and testing datasets.
- Quantify predictor importance and generate spatial predictions of habitat suitability.
- Visualize and summarize model outputs to support ecological interpretation.

## Modeling workflow

The analysis is organized into the following general steps:

1. **Data preparation:** Import occurrence records, remove records with missing coordinates, and prepare spatial data for analysis.
2. **Spatial processing:** Apply the Mongolia national boundary to define the modeling region and prepare occurrence data for environmental extraction.
3. **Environmental predictors:** Prepare climate, elevation, and soil-related environmental layers and screen candidate predictors for multicollinearity.
4. **Pseudoabsence generation:** Generate pseudoabsence records within the modeling region while excluding raster cells containing known presences.
5. **Model fitting:** Fit species-specific BRT models using the `gbm`/`dismo` modeling framework.
6. **Model evaluation:** Assess predictive performance using metrics including area under the receiver operating characteristic curve (AUC), sensitivity, specificity, and true skill statistic (TSS), where calculable.
7. **Spatial prediction and visualization:** Generate suitability predictions, summarize variation among model replicates, and visualize predictions and model outputs.

The workflow uses repeated data partitions and model replicates to examine variation in model performance and predictions. The specific evaluation approach and settings are documented in the analysis code.

## Environmental predictors

Candidate predictors include climatic, topographic, and soil characteristics. The workflow includes screening for multicollinearity before model fitting. The final predictor set depends on the analysis configuration documented in the code.

## Software and packages

The workflow uses R and packages for data manipulation, spatial processing, ecological modeling, and visualization. These include:

- `sf` and `terra` for spatial data processing
- `dplyr` and `readr` for data manipulation and import
- `ggplot2` and `ggspatial` for visualization
- `dismo` and `gbm` for boosted regression tree modeling
- Additional packages for raster processing, model evaluation, and spatial data preparation

Package versions and dependencies should be recorded for the analysis environment used to run the workflow.

## Data availability

**The underlying rodent occurrence datasets and environmental input files are not included in this repository.** Some inputs are unpublished and therefore we are unable to share the data.

The code is shared to demonstrate the modeling workflow. Running the complete analysis requires access to the relevant input datasets, spatial boundary files, environmental raster layers, and any intermediate objects generated by earlier steps. Users must obtain permission to use the applicable data and comply with the original data providers' terms.

This complete workflow cannot be executed from this repository alone without those inputs.
